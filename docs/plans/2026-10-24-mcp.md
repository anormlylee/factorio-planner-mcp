# FactorioLab MCP Implementation Plan

**Goal:** Answer ordinary ChatGPT Factorio questions with sourced recipes and deterministic material balances, without asking the user for a version up front.

**Architecture:** Independent Node ESM service; pin upstream MIT data and Chinese translations with commit/hash provenance. A headless GLPK material-balance adapter follows FactorioLab's net-output and catalyst-productivity rules, without importing Angular. Expose the same read-only tools through Streamable HTTP for ChatGPT and stdio for local clients.

**Tech stack:** Node >=22, MCP TypeScript SDK v1 (JavaScript ESM), Zod, Express, GLPK.js. GLPK.js is GPL-3.0; this prototype uses GPL-3.0-or-later. Upstream data retains its MIT license.

## Task 1: Catalog
Files: `src/catalog.js`, `data/manifest.json`, `tests/catalog.test.js`.
Test Chinese and colloquial search, recipe locations, explicit unsupported datasets, and pinned provenance. Run failing tests; implement read-only catalog and unambiguous resolution; rerun.

## Task 2: Calculation
Files: `src/calculator.js`, `tests/calculator.test.js`.
Test actual quantum processor catalyst return, machine base productivity, module quality/slot restrictions, barrel inventory, and physically impossible locations. Solve recipe cycles with LP rather than recursive arithmetic. Report boundary inputs, gross consumption/production, net balances, selected machines/settings, and unknown startup/transport quantities. Never silently import the requested target. Cross-check the screenshot scenario and a standard iron plate chain by hand.

## Task 3: MCP transports
Files: `src/server.js`, `src/http.js`, `src/stdio.js`, `tests/mcp.test.js`.
Expose dataset listing, search, recipe details, production calculation and barrel transport. Structured errors carry suggestions. Mark all tools read-only. Run real SDK initialize/list/call over in-memory, HTTP and stdio transports. Constrain HTTP bodies and solve time. Default localhost; deployment explicitly sets the listening host.

## Task 4: ChatGPT delivery
Files: `README.md`, `Dockerfile`, `examples/promethium.js`, `examples/chatgpt-instructions.md`.
Document HTTPS endpoint setup, actual ChatGPT connection steps, tool-use guidance, assumptions and remaining limits. Supply a runnable example and save its actual result. Run `npm run check`, the example, a container build if Docker is available, and verify the package contains data/licenses. Public hosting requires a real reachable HTTPS host; do not claim local HTTP is usable from the phone.

Execute in this session under the user's instruction to proceed. No existing source checkout is modified.
